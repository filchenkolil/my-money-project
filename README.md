# MyMoney

Личное приложение для учёта расходов (PWA для iPhone). Данные хранятся только на устройстве.

- `js/` — логика (деньги, даты, хранилище, подсчёты, экспорт и восстановление)
- `tests/` — автотесты, запускаются в браузере (`run-tests.sh`, сервер `tools/serve.ps1`)
- `css/`, `fonts/` — стили и шрифт Manrope (OFL)

Личные данные в репозиторий не кладутся (см. `.gitignore`).
